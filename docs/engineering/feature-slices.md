# 功能切片与界面地图

本文定义第一版按什么用户能力交付。开发时优先按切片做闭环，不要只完成孤立表或页面。

## 页面地图

```text
底部导航
  首页
    今天课程
    本周课程
    快速记录入口
  课程
    孩子列表
    孩子详情
    课程详情
    上课计划
    课包与续费
    上课记录
    联系人
  回顾
    课程统计
    孩子成长时间线
    照片墙
  设置
    标签管理
    备份与恢复
    导出 JSON / CSV
    隐私与本地数据说明
```

## Slice 1：基础壳和本地数据库

目标：App 能启动，具备路由、主题、数据库和基础字典。

交付：

- Flutter 工程初始化。
- Riverpod、go_router、Drift 基础接入。
- 数据库表和迁移框架。
- 系统语义类型和普通标签预置数据。
- 基础错误展示和空状态。

验收：

- App 可启动到首页。
- `flutter analyze` 和基础测试通过。
- 数据库初始化后可读取预置选项。

## Slice 2：孩子与课程建档

目标：用户能建立家庭里的孩子和每个孩子的课程。

交付：

- 添加、编辑、归档孩子。
- 添加、编辑、归档孩子课程。
- 课程默认扣课时、默认时长、地点、机构名称。
- 给课程添加联系人。

验收：

- 能从空 App 完成“添加孩子 -> 添加课程 -> 查看课程详情”。
- 有历史记录的课程不能被无提示硬删除。
- 表单校验覆盖必填项和非法数值。

## Slice 3：上课计划与首页待处理课程

目标：首页能根据计划展示今天和本周要处理的课。

交付：

- 创建每周重复、每天重复、单次、指定日期列表计划。
- 运行时生成近期计划课。
- 首页按日期和时间排序展示。
- 已处理计划课显示状态。

验收：

- 同一个计划能正确生成本周课程。
- 暂停或结束计划不出现在待处理列表。
- 同一节计划课处理后不会重复显示为待处理。

## Slice 4：课包、续费和费用

目标：用户能记录一次购课或续费，并形成课包、费用和购入流水。

交付：

- 添加课包。
- 添加购课费用。
- 自动创建正向课时流水。
- 付款截图附件入口。
- 课包列表显示购买日期、有效期、金额和余额。

验收：

- 一次续费只创建一个新课包，不追加旧课包。
- 金额和课时使用定点整数存储。
- 删除或作废课包不破坏历史流水。

## Slice 5：记录上课、请假、取消和销课

目标：用户从首页点击一节课，在 10 秒内完成常见记录。

交付：

- 处理计划课的底部弹层或详情页。
- 已上课、请假、取消、缺课、补课状态。
- 默认课时、默认时长和默认课包推荐。
- 保存上课记录并自动生成消耗流水。
- 支持手动修改课包和本次扣课时。

验收：

- 扣课记录会生成负向课时流水。
- 不扣课请假只生成上课记录。
- 历史同类型记录能影响下次默认值。
- 课包推荐只在当前课程范围内发生。

## Slice 6：课时账本和调整

目标：用户能看懂每门课的课时变化。

交付：

- 课程课时流水列表。
- 课包余额和课程总余额。
- 手动调整流水。
- 待确认扣课列表。

验收：

- 余额由流水求和得到。
- 调整必须填写备注。
- 待确认项可以补选课包并入账。

## Slice 7：成就、附件和照片墙

目标：用户能保存成长记录和相关照片。

交付：

- 成就记录 CRUD。
- 给上课记录、成就、课包、费用、课程添加附件。
- 附件复制到 App 私有目录。
- 照片墙按孩子、课程、月份筛选。

验收：

- 附件数据库路径不依赖系统绝对路径。
- 删除附件记录时文件处理有明确策略。
- 照片墙不会展示丢失文件为正常图片。

## Slice 8：统计与成长时间线

目标：用户能回顾课程投入和孩子成长。

交付：

- 课程统计卡片。
- 孩子时间线，聚合购课、上课、成就和照片。
- 按课程、月份筛选。

验收：

- 上课次数、时长、消耗课时、投入金额分开计算。
- 周期卡和无固定课时包展示不误导。
- 空数据状态有清晰入口。

## Slice 9：备份、恢复和导出

目标：数据属于用户自己，能完整带走和恢复。

交付：

- 导出完整 zip 备份包。
- `manifest.json` 记录版本、导出时间、数据库版本、附件清单。
- 从备份包恢复。
- 导出 JSON / CSV。

验收：

- 新安装 App 能从备份恢复主要数据和附件。
- 备份包缺文件或版本不兼容时能提示，不能半恢复。
- 恢复前有明确用户确认。

## Slice 10：本地通知和打磨

目标：增强日常提醒，但不改变核心账本模型。

交付：

- 本周课程提醒。
- 课时不足或课包快过期提醒。
- 常见空状态、加载态、错误态打磨。

验收：

- 通知可关闭。
- 通知数据来源于本地计划和余额。
- 不依赖云服务。
