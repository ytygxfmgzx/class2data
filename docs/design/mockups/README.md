# Mockups

本目录存放可选的静态高保真 UI 视觉稿。

本项目 UI 确认主产物是 [../prototypes/html/README.md](../prototypes/html/README.md) 中的高保真可交互 HTML 原型。如果 HTML 原型已经能表达视觉风格、布局和状态，可以不单独输出静态 mockup。

推荐格式：

- `.png`：高保真页面导出图。
- `.jpg`：仅在图片较大且不需要透明度时使用。

高保真稿必须体现：

- 真实中文文案。
- 颜色、字体、间距、图标和组件状态。
- 手机端实际视口。
- 正常、空、错误等关键状态。

静态 mockup 不是进入 Flutter 开发的必需门禁；HTML 原型和用户确认才是必需门禁。
