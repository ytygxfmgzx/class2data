## 2. 页面详细规格

### S01 首页

**页面类型**：Tab 页，App 启动默认页

**功能定位**：看课程和快速录入。首页包含课程日历，不再另设课程日历 Tab。

**核心区域**：

| 区域 | 内容 |
| --- | --- |
| 顶部概览 | 今天日期、待处理课程数量、课时不足或课包到期摘要 |
| 快捷录入 | 记录上课、录入课时包、录入课程、录入成就、录入孩子 |
| 课程日历筛选 | 孩子筛选、课程筛选 |
| 课程日历 | 日 / 周视图，展示筛选后的课程块 |
| 当前日期课程列表 | 待处理和已处理课程 |

**入口**：

- App 启动。
- 底部 Tab“首页”。
- 通知点击可跳转到首页并定位课程。

**出口**：

- 记录上课 -> S04
- 录入课时包 -> S05，必要时先选择孩子和课程
- 录入课程 -> S06，必要时先录入孩子
- 录入成就 -> S07，必要时先选择孩子
- 录入孩子 -> S08
- 日历课程块 -> S04、S12 或上课记录详情

**页面状态**：

| 状态 | 显示内容 |
| --- | --- |
| 正常 | 快捷录入、筛选器、课程日历、当前日期课程 |
| 无孩子 | 强引导录入孩子 |
| 有孩子无课程 | 引导录入课程 |
| 有课程无计划 | 引导去设置 -> 课程管理 -> 课程计划维护，或手动补录 |
| 筛选无结果 | 提示清除孩子/课程筛选 |
| 加载中 | 保持首页布局骨架 |

**关键交互规则**：

- 快捷录入顺序不可调整。
- 课程日历默认“全部孩子 + 全部课程”。
- 孩子筛选影响课程筛选候选项。
- 课程筛选后，日历只展示该课程排期。
- 日历课程块必须显示孩子、课程、时间、地点和处理状态。

### S02 成长动态

**页面类型**：Tab 页

**功能定位**：像朋友圈一样展示所有孩子的成长记录，而不是展示孩子列表。

**核心区域**：

| 区域 | 内容 |
| --- | --- |
| 孩子筛选器 | 全部、孩子 A、孩子 B |
| 快捷操作 | 录入成就 |
| 照片墙入口 | 最近照片预览、进入照片墙 |
| 成长动态流 | 上课、成就、照片、购课等按日期倒序展示 |
| 孩子摘要入口 | 孩子头像和名称，可进入孩子详情 |

**入口**：

- 底部 Tab“成长”。
- 首页录入成就保存后返回。
- 成就通知或照片入口。

**出口**：

- 录入成就 -> S07
- 照片墙入口 -> S18
- 动态卡 -> 上课记录详情、成就详情、课包详情或照片查看器
- 孩子摘要 -> S13

**页面状态**：

| 状态 | 显示内容 |
| --- | --- |
| 正常 | 全部孩子动态流 |
| 筛选后 | 单个孩子动态流 |
| 无孩子 | 引导从首页或设置录入孩子 |
| 有孩子无动态 | 引导录入课程、记录上课或录入成就 |
| 无照片 | 照片墙入口显示空状态，引导从上课记录或成就添加照片 |
| 附件异常 | 动态卡显示附件缺失或失败状态 |

**关键交互规则**：

- 默认展示全部孩子动态。
- 照片墙入口跟随当前孩子筛选。
- 孩子列表不能作为本页主体。
- 动态按日期倒序分组。
- 上课记录和成就都必须进入动态流。

### S03 设置

**页面类型**：Tab 页

**功能定位**：基础数据维护和系统设置。

**核心区域**：

| 分组 | 菜单项 |
| --- | --- |
| 数据管理 | 孩子管理、课程管理、标签管理 |
| 数据安全 | 备份与恢复 |
| 提醒 | 通知设置 |
| 关于 | 版本信息、说明 |

**入口**：底部 Tab“设置”

**出口**：

- 孩子管理 -> S09
- 课程管理 -> S10
- 标签管理 -> S22
- 备份与恢复 -> S20
- 通知设置 -> S21

**页面状态**：

| 状态 | 显示内容 |
| --- | --- |
| 正常 | 设置菜单 |
| 通知未授权 | 在通知菜单项显示权限状态 |
| 未备份风险 | 可显示备份提醒 |

### S04 记录上课

**页面类型**：弹层或全屏页

**功能定位**：快速记录上课、请假、取消、缺课和补课。

**入口**：

- 首页快捷入口“记录上课”。
- 首页日历课程块。
- 课程详情“记录上课”。

**出口**：

- 保存 -> 回到触发页并刷新状态。
- 取消 -> 回到触发页。
- 无课包且需扣课 -> 可转入 S05 或保存待确认。

**页面状态**：

| 状态 | 显示内容 |
| --- | --- |
| 快速记录 | 默认值已填，突出保存 |
| 手动补录 | 可选择孩子、课程、历史日期 |
| 无可用课包 | 添加课包、待确认、本次不扣课 |
| 附件失败 | 显示图片保存失败状态 |

### S05 课包表单

**页面类型**：二级页

**功能定位**：录入购课、续费、赠课或周期卡。

**入口**：

- 首页快捷入口“录入课时包”。
- 课程详情“录入课时包 / 购课续费”。
- 记录上课无可用课包时的引导。

**关键字段**：

- 课程、课包类型、购买日期、生效日期、到期日期、总课时、金额、备注、付款截图。

### S06 课程表单

**页面类型**：二级页

**功能定位**：录入或编辑课程。

**入口**：

- 首页快捷入口“录入课程”。
- 设置 -> 课程管理 -> 添加课程。
- 课程详情编辑。

**关键字段**：

- 孩子、课程名称、分类、机构、地点、默认扣课时、默认时长、备注。

### S07 成就表单

**页面类型**：二级页

**功能定位**：录入或编辑孩子成就。

**入口**：

- 首页快捷入口“录入成就”。
- 成长 Tab 快捷操作。
- 孩子详情或课程详情。

**关键字段**：

- 孩子、日期、类型、标题、说明、关联课程、附件。

### S08 孩子表单

**页面类型**：二级页

**功能定位**：录入或编辑孩子。

**入口**：

- 首页快捷入口“录入孩子”。
- 设置 -> 孩子管理 -> 添加 / 编辑孩子。
- 孩子详情编辑。

**关键字段**：

- 名称、昵称、生日、头像、备注。

### S09 孩子管理

**页面类型**：二级页

**功能定位**：低频维护孩子资料。

**入口**：设置 -> 孩子管理

**出口**：

- 添加孩子 -> S08
- 编辑孩子 -> S08
- 孩子详情 -> S13

**关键交互规则**：

- 有历史记录的孩子不能无提示硬删除，应优先归档。
- 成长回顾不从这里开始；成长动态仍在 S02。

### S10 课程管理

**页面类型**：二级页

**功能定位**：低频维护课程资料，并进入课程计划维护。

**入口**：设置 -> 课程管理

**出口**：

- 添加课程 -> S06
- 编辑课程 -> S06
- 课程详情 -> S12
- 课程计划维护 -> S11

**核心区域**：

- 孩子筛选、课程列表、添加课程、计划维护入口。

### S11 课程计划维护

**页面类型**：二级页

**功能定位**：维护上课计划，计划保存后回流到首页课程日历。

**入口**：

- 设置 -> 课程管理 -> 课程计划维护。
- 课程详情 -> 课程计划。

**出口**：

- 添加计划 -> S14
- 编辑计划 -> S14
- 查看冲突 -> 冲突详情或计划表单

**页面状态**：

| 状态 | 显示内容 |
| --- | --- |
| 正常 | 计划列表，按孩子、课程、状态筛选 |
| 无计划 | 引导添加计划 |
| 有冲突 | 显示冲突课程、日期、时间 |

### S12 课程详情

**页面类型**：二级页

**功能定位**：从首页课程日历进入后的课程总览页，同时管理课包、计划、记录、账本、联系人和统计。

**入口**：

- 首页日历课程块。
- 设置 -> 课程管理。
- 成长动态中的课程入口。

**出口**：

- 记录上课 -> S04
- 录入课时包 -> S05
- 课程计划维护 -> S11
- 添加计划 -> S14
- 课时账本 -> S15
- 联系人表单 -> S17
- 编辑课程 -> S06

**核心区域**：

| 区域 | 内容 |
| --- | --- |
| 课程头部 | 孩子、课程名称、机构、地点、状态、编辑入口 |
| 快捷操作 | 记录上课、录入课时包、修改课程计划、编辑课程 |
| 课程总览 | 已购课时、已花费金额、剩余课时、待确认扣课、上课次数、累计实际时长、课程持续周期 |
| 课程计划日历 | 日 / 周视图、未来计划课、已处理记录、冲突提示 |
| 课包与费用 | 课包列表、费用记录、到期提醒 |
| 上课记录 | 历史记录，按日期倒序 |
| 课时账本 | 流水入口、待确认扣课、手动调整 |
| 联系人与备注 | 老师、教练、顾问等联系人 |

**指标口径**：

| 指标 | 口径 |
| --- | --- |
| 已购课时 | 固定课时课包的购入课时合计 |
| 已花费金额 | 费用记录金额合计 |
| 剩余课时 | 课程课时流水求和 |
| 上课次数 | 实际发生的已上课 / 补课记录数 |
| 累计实际时长 | 上课记录实际时长合计 |
| 课程持续周期 | 从第一条有效购课、计划或上课记录到当前日期 / 最后一条记录 |

**关键交互规则**：

- 从首页日历点击未处理课程时，可优先提供“记录上课”和“查看详情”两个动作。
- 从首页日历点击课程详情后，必须能看见这门课的整体投入、余额和时间消耗。
- 课程详情可直接修改课程名称、机构、地点、默认扣课时、默认时长等基础信息。
- 课程详情可进入课程计划维护，添加、编辑、暂停或结束计划。
- 课程计划修改保存后，首页课程日历必须刷新对应排期。
- 周期卡或不限次卡不伪造课时余额，应展示有效期或不限次语义。

### S13 孩子详情

**页面类型**：二级页

**功能定位**：查看单个孩子资料、该孩子动态、照片和课程摘要。

**入口**：

- 成长 Tab 孩子摘要。
- 设置 -> 孩子管理。

**出口**：

- 编辑孩子 -> S08
- 录入成就 -> S07
- 照片墙 -> S18
- 课程卡 -> S12

### S14 计划表单

**页面类型**：二级页

**功能定位**：添加或编辑上课计划。

**入口**：

- 课程计划维护。
- 课程详情。

**关键字段**：

- 计划类型、上课类型、开始日期、结束日期、开始时间、结束时间、星期或日期列表、地点、状态。

### S15 课时账本

**页面类型**：二级页

**功能定位**：查看课时流水、余额和待确认扣课。

**入口**：课程详情

**出口**：

- 手动调整 -> S16
- 待确认项 -> 选择课包并入账

### S16 课时调整表单

**页面类型**：弹层或全屏页

**功能定位**：手动调整课时流水。

**入口**：课时账本

**关键字段**：

- 调整方向、课时数、关联课包、备注。

### S17 联系人表单

**页面类型**：二级页

**功能定位**：添加或编辑课程联系人。

**入口**：课程详情

**关键字段**：

- 姓名、角色、电话、微信、备注。

### S18 照片墙

**页面类型**：二级页

**功能定位**：集中展示所有照片，作为孩子成长照片回顾的主入口。

**入口**：

- 成长动态。
- 孩子详情。
- 课程详情。

**核心区域**：

| 区域 | 内容 |
| --- | --- |
| 筛选器 | 孩子、课程、月份、来源对象、类型 |
| 照片网格 | 所有符合筛选条件的照片缩略图 |
| 照片摘要 | 发生时间、孩子、课程或来源类型的简短提示 |

**筛选维度**：

- 孩子、课程、月份、来源对象、类型。

**关键交互规则**：

- 从成长页进入时，照片墙继承当前孩子筛选。
- 默认展示筛选范围内所有照片。
- 点击照片进入照片查看器（S19），查看大图和事件语境。
- 附件文件丢失时，照片格显示异常状态，不能展示为正常图片。

### S19 照片查看器

**页面类型**：全屏页

**功能定位**：查看照片大图，支持左右滑动，并展示这张照片发生的情况。

**入口**：

- 照片墙。
- 成长动态附件。
- 上课记录或成就附件。

**核心区域**：

| 区域 | 内容 |
| --- | --- |
| 照片大图 | 当前照片，支持缩放和平移 |
| 左右滑动 | 查看同一筛选结果中的前一张 / 后一张 |
| 事件语境 | 来源对象、发生时间、孩子、关联课程、标题或备注 |
| 跳转入口 | 查看对应上课记录、成就记录、课包或课程详情 |

**事件语境展示规则**：

- 来源为上课记录：展示上课日期、课程、状态、实际时长、消耗课时和备注。
- 来源为成就：展示成就日期、成就类型、标题、关联课程和说明。
- 来源为课包或费用：展示购买日期、课程、课包类型、金额和备注。
- 来源为课程附件：展示课程、附件类型和备注。
- 关联对象已归档时，仍展示历史快照，不丢失照片上下文。
- 附件文件丢失时，展示缺失状态和照片元数据。

### S20 备份与恢复

**页面类型**：二级页

**功能定位**：导出完整备份、从备份恢复、导出 JSON / CSV。

**入口**：设置

**关键状态**：

- 正常、导出中、恢复确认、恢复失败、版本不兼容、附件缺失。

### S21 通知设置

**页面类型**：二级页

**功能定位**：配置本地通知。

**入口**：设置

**关键状态**：

- 权限已开启、权限未授予、某类提醒关闭。

## 5. P3 通过标准

- 页面清单只有首页、成长、设置三个 Tab 页。
- 首页包含五个高频快捷入口和课程日历。
- 首页课程日历支持按孩子和课程筛选。
- 不存在独立课程日历 Tab。
- 成长 Tab 默认是所有孩子成长动态流，并提供照片墙入口，不是孩子列表。
- 设置中包含孩子管理、课程管理和课程计划维护。
- 课程计划维护保存后能反映到首页课程日历。
