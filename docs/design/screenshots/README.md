# Screenshots

本目录存放开发实现后的页面截图，用于 UI 还原验收。

截图命名建议：

```text
home-android-normal.png
home-android-empty.png
record-class-android-normal.png
record-class-android-error.png
```

验收时对照：

- `prototypes/html/`：页面结构、交互、视觉样式是否一致。
- `wireframes/`：如果存在，用于辅助检查页面结构。
- `mockups/`：如果存在，用于辅助检查静态视觉样式。
- `screen-specs/`：状态、文案和交互是否一致。

如果设计稿和实现截图不一致，必须记录差异原因：设计调整、实现限制或缺陷。
