## 1. 页面目标

首页用于回答两个问题：

- 今天和本周有哪些课，什么时候上。
- 家长现在最常用的录入动作在哪里。

首页必须紧凑高效，不浪费屏幕空间。

## 2. 页面结构

```text
紧凑标题行（日期 + 待处理数 + 右上角加号按钮）
筛选 Chip 行（孩子 + 课程）
周视图（单行 7 列日期）
当日课程列表
底部导航
```

## 3. 核心区域

### 3.1 紧凑标题行

内容：

- 今天日期（14px `--text-2`）。
- 待处理课程数量（如"3 节待处理"）。
- 课时不足警示（如有，用 `--red` 文字）。
- 右侧"+"按钮。

规则：

- 标题行高 44px，不做 Large Title。
- 警示超过 1 条时只展示最重要一条。

### 3.2 快捷入口（右上角加号）

标题行右侧"+"按钮，点击弹出菜单，菜单项顺序固定：

1. 记录上课（字重 600，排在首位）
2. 录入课时包
3. 录入课程
4. 录入成就
5. 录入孩子

规则：

- 弹出菜单白底，1px `--border`，4px 圆角，每行高 44px。
- 点击菜单项执行操作，点击遮罩关闭。
- 前置条件不足时点击后给出下一步引导。

### 3.3 筛选 Chip 行

筛选项：

- 孩子：全部（默认）、单个孩子。使用 28px 高头像 Chip。
- 课程：全部（默认）、单门课程。使用 28px 高文字 Chip。

规则：

- 默认"全部孩子 + 全部课程"。
- 选择孩子后，课程筛选只展示该孩子课程。
- 选择课程后，日历只展示该课程排期。
- 筛选无结果时提供"清除筛选"和"维护课程计划"。

### 3.4 周视图

结构：

- 单行 7 列，每格只显示日期数字（14px）。
- 今天用 `--blue` 文字 + 粗体。
- 选中日期下方 2px `--blue` 短横线。
- 左右箭头切换周。

规则：

- 有课程的日期下方加小圆点（4px `--blue`）。
- 选中日期与课程列表联动。

### 3.5 当日课程列表

每条课程块紧凑展示：

```text
18:30  钢琴 · 安安           [待处理]
       星海音乐中心        [记录]
```

- 时间左对齐（14px `--text-1`）。
- 课程 + 孩子（14px `--subtitle`）。
- 状态标签右对齐（12px，语义色背景 + 文字，2px 圆角）。
- "记录"按钮（12px `--blue` 文字按钮）仅对未处理课程显示。
- 点击课程块进入课程详情。
- 点击"记录"按钮直接进入记录上课。

## 4. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 正常 | 快捷按钮 + 筛选 + 周视图 + 课程列表 | 记录上课 |
| 无孩子 | "先添加一个孩子" | 录入孩子 |
| 有孩子无课程 | "给孩子添加一门课程" | 录入课程 |
| 有课程无计划 | "这门课还没有计划" | 维护课程计划 |
| 筛选无结果 | 保留筛选器，显示无结果 | 清除筛选 |
| 加载中 | 骨架屏 | 无 |
| 错误 | 错误原因 + 重试 | 重试 |

## 5. 关键交互

- 点击"记录上课"：筛选范围内今天只有一节待处理课时直接进入；否则进入课程选择。
- 点击"录入课时包"：单门课程时带入课程；否则先选孩子和课程。
- 点击"录入课程"：单个孩子时带入孩子；否则先选孩子。
- 点击课程块：进入课程详情。
- 点击"记录"按钮：直接进入记录上课弹层。
- 切换底部 Tab：首页保留最近筛选状态。

## 6. 文案

- 页面标题：`今天`
- 快捷入口：`记录上课`、`录入课时包`、`录入课程`、`录入成就`、`录入孩子`
- 空状态：`还没有孩子`、`还没有课程`、`这门课还没有计划`、`没有符合筛选的课程`

## 7. 视觉要求

- 遵循 visual-system.md v0.5 token。
- 页面背景 `--bg`，课程块用 `--bg-card` + 1px `--border` + 4px 圆角。
- 周视图紧凑，单行占高 40px 以内。
- 课程列表每行占高 56px。
- 不使用大卡片、渐变、阴影或装饰元素。
- 信息密度目标：首屏展示完整周视图 + 2-3 条课程。

## 8. 验收标准

- 首页只有首页、成长、设置三个底部 Tab。
- 快捷按钮条顺序正确，"记录上课"视觉突出。
- 周视图默认展示本周，选中今天。
- 课程日历默认展示全部孩子、全部课程。
- 支持按孩子和课程筛选。
- 点击课程能进入课程详情。
- 未处理课程有"记录"按钮。
- 空状态都有明确下一步。
