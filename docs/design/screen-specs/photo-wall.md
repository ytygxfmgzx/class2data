## 1. 页面目标

照片墙是集中展示所有照片的入口。照片不是孤立图片，点开后必须能看到事件语境。

## 2. 照片墙结构

```text
紧凑顶部栏（返回 + "照片墙"）
筛选 Chip 行（孩子 + 课程 + 月份）
照片网格（3 列）
```

## 3. 照片墙核心区域

### 3.1 筛选 Chip 行

筛选维度：

- 孩子。
- 课程。
- 月份。

规则：

- 从成长页进入时继承当前孩子筛选。
- 默认展示筛选范围内所有照片。
- Chip 28px 高，4px 圆角，可横向滚动。

### 3.2 照片网格

3 列正方形缩略图，间距 2px。

每张照片项：

- 正方形缩略图（1:1 裁切）。
- 下方日期（10px `--text-3`）。

规则：

- 图片不能拉伸变形。
- 文件缺失时显示灰色占位 + 异常图标。
- 点击进入照片查看器。

## 4. 照片查看器结构

```text
深色背景（#111111）
照片大图
底部事件语境信息区
左右滑动
```

## 5. 照片查看器核心区域

### 5.1 照片大图

- 居中展示。
- 左右滑动切换前一张/后一张。
- 支持缩放和平移。

### 5.2 事件语境信息区

底部半透明信息区：

- 来源对象（12px 白色）。
- 发生时间。
- 孩子。
- 关联课程。
- 标题或备注。
- "查看记录" 文字链接（`--blue`）。

来源对象规则：

| 来源 | 展示内容 |
| --- | --- |
| 上课记录 | 日期、课程、状态、时长、课时 |
| 成就 | 日期、类型、标题、课程 |
| 课包/费用 | 购买日期、课程、金额 |
| 课程附件 | 课程、类型 |

规则：

- 关联对象已归档时展示历史快照。
- 附件文件丢失时展示缺失状态和元数据。

## 6. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 正常 | 照片网格 | 点开照片 |
| 无照片 | "还没有照片" | 去记录上课 / 录入成就 |
| 筛选无结果 | "没有符合筛选的照片" | 清除筛选 |
| 文件缺失 | 灰色占位 | 查看元数据 |

## 7. 关键交互

- 点击照片：进入查看器。
- 左右滑动：切换照片。
- 点击"查看记录"：跳转对应详情。
- 返回：回到照片墙保留筛选。

## 8. 文案

- 页面标题：`照片墙`
- 空状态：`还没有照片`
- 异常：`照片文件找不到了`
- 查看入口：`查看记录`

## 9. 视觉要求

- 遵循 visual-system.md v0.5 token。
- 照片网格 3 列，间距 2px，无圆角。
- 查看器背景 `#111111`，文字白色 12px。
- 语境信息区半透明黑色背景，不遮挡照片主体。
- 不使用复杂相册装饰。

## 10. 验收标准

- 成长页可进入照片墙。
- 照片墙集中展示所有照片。
- 支持按孩子、课程、月份筛选。
- 点开照片后可左右滑动。
- 照片查看器展示事件语境。
- 文件缺失有异常状态。
