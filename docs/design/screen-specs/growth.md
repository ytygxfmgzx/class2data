## 1. 页面目标

成长页用于回看孩子轨迹，默认展示所有孩子的成长动态。

核心问题：

- 最近孩子们上了什么课。
- 有哪些成就、照片和购课记录。
- 如何快速进入照片墙。

## 2. 页面结构

```text
紧凑标题行
孩子筛选（头像 Chip）
照片墙入口横条
成长动态列表
底部导航
```

## 3. 核心区域

### 3.1 孩子筛选

- 头像 Chip 行，28px 高，横向可滚动。
- 默认"全部"，可切换单个孩子。
- 切换后照片墙入口和动态流跟随筛选。

### 3.2 照片墙入口横条

紧凑横条，56px 高：

- 左侧：相机图标 + "照片墙" 文字 + 照片数量。
- 右侧：最近 3 张 24x24 缩略图 + 箭头。

规则：

- 无照片时显示"还没有照片" + 添加提示。
- 点击进入照片墙，继承孩子筛选。

### 3.3 成长动态列表

动态类型：

- 上课记录。
- 成就记录。
- 照片记录。
- 购课记录。

每条动态行（56-64px）：

```text
[缩略图]  2026-05-09  安安 · 钢琴 · 已上课
          实际时长 45 分钟 · 消耗 1 课时
```

- 日期 + 孩子名 + 课程名 + 事件类型（14px `--subtitle`）。
- 辅助信息（12px `--text-3`）。
- 有照片的动态左侧显示 32x32 小缩略图。
- 无照片时左侧显示事件类型图标。

规则：

- 按日期倒序分组，日期分组标签 12px `--text-3`。
- 同一天多个事件按时间倒序。
- 点击动态进入对应详情。

## 4. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 正常 | 照片墙入口 + 动态列表 | 查看动态 |
| 无孩子 | "先添加一个孩子" | 录入孩子 |
| 有孩子无动态 | "还没有成长记录" | 录入课程 / 记录上课 |
| 无照片 | 照片墙入口空状态 | 去记录上课 |
| 筛选无结果 | "这个孩子还没有动态" | 切回全部 |
| 附件异常 | 缩略图位置异常状态 | 查看详情 |

## 5. 关键交互

- 切换孩子筛选：刷新照片墙入口和动态列表。
- 点击照片墙入口：进入照片墙。
- 点击动态：进入对应详情（上课记录/成就/课包）。
- 点击课程名：进入课程详情。

## 6. 文案

- 页面标题：`成长`
- 入口：`照片墙`
- 空状态：`还没有成长记录`、`还没有照片`、`这个孩子还没有动态`

## 7. 视觉要求

- 遵循 visual-system.md v0.5 token。
- 动态列表使用紧凑列表行，行高 56-64px，1px `--border` 分割线。
- 照片墙入口横条背景 `--bg-card`，1px `--border`，4px 圆角。
- 日期分组标签不占多余空间，12px `--text-3` + 上方 8px 间距。
- 不使用大卡片或社交媒体式装饰。

## 8. 验收标准

- 默认展示全部孩子动态。
- 照片墙入口可见且紧凑。
- 切换孩子后列表和照片墙入口同步筛选。
- 点击动态可进入对应详情。
- 不以孩子列表作为主体内容。
