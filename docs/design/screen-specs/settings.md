## 1. 页面目标

设置页承载低频管理和系统配置。日常看课、记录、成长回顾不从这里开始。

## 2. 设置首页结构

iOS 风格分组列表：

```text
[数据管理]
  孩子管理          >
  课程管理          >
  标签管理          >
[数据安全]
  备份与恢复        >
[提醒]
  通知设置          >
[关于]
  版本信息
底部导航
```

规则：

- 分组标题 12px `--text-3`，左对齐，距上方 20px。
- 列表容器 `--bg-card`，无圆角。
- 行高 48px，1px `--border` 分割线。
- 每行：左侧图标 + 主文本，右侧副文本 + 箭头。
- 组间距 20px。

## 3. 孩子管理

列表项（48px 行高）：

- 头像（32x32）。
- 名称。
- 年龄或生日（12px `--text-3`）。
- 课程数量（右侧副文本）。
- 状态标签（如已归档）。

操作：

- 添加孩子。
- 编辑孩子。
- 归档孩子（`--red` 文字，需确认）。
- 进入孩子详情。

## 4. 课程管理

筛选 Chip 行：孩子 + 状态。

列表项（48px 行高）：

- 课程名。
- 孩子名（12px `--text-3`）。
- 机构（12px `--text-3`）。
- 剩余课时或有效期（右侧）。
- 状态标签。

操作：

- 添加课程。
- 编辑课程。
- 归档课程（需确认）。
- 进入课程详情。
- 进入课程计划维护。

## 5. 课程计划维护

筛选 Chip 行：孩子 + 课程 + 状态。

计划列表项（48px 行高）：

- 课程名 + 孩子名。
- 规则摘要（每周三 18:00-19:00）。
- 状态标签。
- 冲突标记（`--orange`）。

操作：

- 添加计划。
- 编辑计划。
- 暂停 / 结束计划。
- 查看冲突详情。

保存规则：

- 计划保存后首页课程日历刷新。
- 同一孩子时间冲突时提示，但允许用户确认继续。

## 6. 备份与恢复

列表形式：

- 导出完整备份（主按钮样式）。
- 从备份恢复。
- 导出 JSON / CSV。

规则：

- 恢复前必须确认。
- 失败时说明原因。
- 不产生半恢复状态。

## 7. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 设置正常 | 分组菜单列表 | 进入管理 |
| 无孩子 | "还没有孩子" | 添加孩子 |
| 无课程 | "还没有课程" | 添加课程 |
| 无计划 | "还没有计划" | 添加计划 |
| 有冲突 | 计划行 `--orange` 标记 | 查看冲突 |
| 通知未授权 | 通知设置显示权限状态 | 去开启 |
| 未备份 | 设置首页可提示备份 | 导出备份 |

## 8. 关键交互

- 点击孩子管理：进入孩子列表。
- 点击课程管理：进入课程列表。
- 点击课程计划维护：进入计划列表。
- 点击备份恢复：进入备份恢复页。
- 归档/删除操作需确认弹窗。

## 9. 文案

- 分组：`数据管理`、`数据安全`、`提醒`、`关于`
- 菜单：`孩子管理`、`课程管理`、`标签管理`、`备份与恢复`、`通知设置`
- 操作：`添加孩子`、`添加课程`、`添加计划`

## 10. 视觉要求

- 遵循 visual-system.md v0.5 token。
- iOS 风格分组列表，白底无圆角。
- 行高 48px，1px `--border` 分割线。
- 图标 20px `--text-2`，主文本 15px `--subtitle`，副文本 12px `--text-3`。
- 危险操作文字 `--red`，确认弹窗。
- 不使用大卡片堆叠。

## 11. 验收标准

- 设置页包含孩子管理、课程管理、课程计划维护入口。
- 孩子和课程可添加、编辑、归档。
- 计划可添加、编辑、暂停、结束。
- 计划修改后首页日历可反映。
- 备份、通知、标签入口存在。
