## 1. 页面目标

课程详情是从首页课程块点击后的总览页。让家长一眼看懂这门课的投入、余额、计划和历史。

必须回答：

- 买了多少课。
- 花了多少钱。
- 还剩多少课。
- 上了多少次、多久。
- 持续了多长周期。

## 2. 页面结构

```text
紧凑顶部栏（返回 + 课程名 + 编辑）
课程头部行（孩子 + 机构 + 状态）
紧凑指标网格（2x3 或 3x2）
操作按钮行（记录上课 + 录入课时包）
Tab 切换（计划 / 记录 / 课包）
Tab 内容列表
```

## 3. 核心区域

### 3.1 紧凑顶部栏

- 返回图标 + 课程名（15px/600）+ 编辑图标。
- 白底 + 底部 1px `--border`。

### 3.2 课程头部行

一行展示：

- 孩子名。
- 课程名。
- 机构名。
- 课程状态标签（2px 圆角色块）。

### 3.3 紧凑指标网格

2x3 或 3x2 紧凑网格：

| 指标 | 口径 | 色彩规则 |
| --- | --- | --- |
| 已购课时 | 固定课时课包购入合计 | `--text-1` |
| 已花费金额 | 费用金额合计 | `--text-1` |
| 剩余课时 | 课时流水求和 | 正常 `--green`，不足 `--red` |
| 待确认扣课 | 未明确课包的扣课流水 | `--orange`（有值时） |
| 上课次数 | 已上课 + 补课等实际记录数 | `--text-1` |
| 累计时长 | 实际时长合计 | `--text-1` |

每个指标格：

- 标签 12px `--text-3`。
- 数字 20px/600 `--text-1`（或语义色）。
- 背景 `--bg-card`，1px `--border`，圆角 4px，内边距 10px。
- 网格间距 1px。

### 3.4 操作按钮行

- "记录上课"主按钮（蓝底白字 4px 圆角）。
- "录入课时包"次按钮（白底边框 4px 圆角）。
- 水平排列，各占一半宽度。

### 3.5 Tab 切换

三个 Tab：

- 计划。
- 记录。
- 课包。

规则：

- 使用底部下划线指示器（2px `--blue`）。
- 未选中 Tab 文字 `--text-3`，选中 `--text-1`。

### 3.6 计划列表

每行展示：

- 日期。
- 时间段。
- 状态。
- 冲突标记（如有）。

### 3.7 记录列表

每行展示：

- 日期。
- 状态标签。
- 实际时长。
- 消耗课时。
- 缩略图（如有图片）。

日期倒序。

### 3.8 课包列表

每行展示：

- 课包类型。
- 总课时 / 剩余课时。
- 购买日期。
- 到期日期。
- 金额。

## 4. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 正常 | 指标网格 + Tab 列表 | 记录上课 |
| 无课包 | 余额区提示"未录入课包" | 录入课时包 |
| 无计划 | 计划 Tab 空状态 | 添加计划 |
| 无记录 | 记录 Tab 空状态 | 记录上课 |
| 待确认扣课 | 指标区 `--orange` 高亮 | 处理待确认 |
| 附件异常 | 记录行图片异常 | 查看记录 |

## 5. 关键交互

- 点击编辑：进入课程表单。
- 点击"记录上课"：进入记录上课弹层。
- 点击"录入课时包"：进入课包表单。
- 点击记录行：进入记录详情。
- 点击课包行：进入课包详情。
- 切换 Tab：刷新下方列表。

## 6. 文案

- 指标标签：`已购课时`、`已花费`、`剩余课时`、`待确认`、`上课次数`、`累计时长`
- Tab：`计划`、`记录`、`课包`
- 操作：`记录上课`、`录入课时包`

## 7. 视觉要求

- 遵循 visual-system.md v0.5 token。
- 指标网格紧凑，6 个指标总高度不超过 120px。
- 列表行高 48px，1px `--border` 分割线。
- 状态标签 2px 圆角色块，12px 字号。
- 不使用大卡片、阴影、渐变。
- 整体信息密度高，减少滚动。

## 8. 验收标准

- 从首页课程块可进入课程详情。
- 指标网格展示购买、花费、余额、次数、时长。
- 课时不足时数字变红。
- 三个 Tab 可切换。
- 可记录上课、录入课包。
- 可编辑课程基础信息。
