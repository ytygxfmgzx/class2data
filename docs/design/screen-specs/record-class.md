## 1. 页面目标

支持家长快速记录一节课。常见路径：

```text
打开 App -> 点课程块上"记录" -> 保存
```

## 2. 页面形式

- 从首页课程块进入时，使用底部弹层。
- 手动补录历史记录时，使用全屏表单页。

## 3. 弹层结构

```text
拖拽条
标题"记录上课" + 关闭按钮
课程信息摘要行（一行）
状态选择（横向紧凑标签组）
表单字段（紧凑列表行）
底部保存按钮
```

## 4. 核心字段

| 字段 | 必填 | 默认值 |
| --- | --- | --- |
| 孩子 | 是 | 从课程带入 |
| 课程 | 是 | 从入口带入 |
| 日期 | 是 | 计划日期 / 今天 |
| 时间 | 否 | 计划时间 |
| 状态 | 是 | 已上课 |
| 扣课时 | 是 | 最近记录 > 课程默认值 |
| 实际时长 | 否 | 最近记录 > 课程默认值 |
| 课包 | 否 | 自动推荐 |
| 图片 | 否 | 无 |
| 备注 | 否 | 无 |

状态选项（横向紧凑标签组）：

- 已上课（默认，`--bg-green` + `--green`）
- 请假（`--bg` + `--text-3`）
- 取消（`--bg` + `--text-3`）
- 缺课（`--bg-red` + `--red`）
- 补课（`--bg-blue` + `--blue`）

## 5. 默认值规则

优先级：

1. 最近一次同课程、同上课类型记录。
2. 最近一次同课程记录。
3. 课程默认扣课时和默认时长。
4. 用户手动输入。

## 6. 状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 快速记录 | 字段自动带出，突出保存 | 保存 |
| 手动补录 | 可选孩子、课程、历史日期 | 保存 |
| 无可用课包 | 提示添加课包、待确认、本次不扣课 | 待确认 |
| 推荐不确定 | 课包显示待确认 | 手动选择 |
| 附件失败 | 记录保存，图片显示失败 | 重试附件 |
| 校验失败 | 字段附近提示 | 修正 |

## 7. 关键交互

- 点击状态标签：切换状态并同步建议扣课时。
- 扣课时步进器：±0.5，紧凑行内展示。
- 选择课包：下拉列表展示可用课包。
- 添加图片：缩略图 + 添加按钮，最多 9 张。
- 保存：创建上课记录；扣课时大于 0 时创建负向课时流水。
- 无课包保存：允许保存为待确认扣课。

## 8. 文案

- 标题：`记录上课`
- 主按钮：`保存记录`
- 待确认：`先记下来，稍后确认扣课`
- 无课包：`还没有可用课包`

## 9. 视觉要求

- 底部弹层顶部圆角 6px，白底。
- 状态标签：2px 圆角色块，28px 高，横向排列。
- 表单行：标签 12px `--text-2` 在上，输入框 40px 高 4px 圆角在下。
- 步进器：紧凑内联，左右 ± 按钮 + 中间数字。
- 保存按钮：蓝底白字，圆角 4px，高 40px，固定弹层底部。
- 课程摘要行不超一行，14px `--text-2`。

## 10. 验收标准

- 从首页"记录"按钮可打开弹层。
- 默认状态为已上课。
- 默认扣课时和时长可修改。
- 可添加图片。
- 可保存待确认扣课。
- 保存后首页课程状态刷新。
