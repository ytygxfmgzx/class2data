# Prototypes

本目录存放可交互原型，用于验证页面跳转、弹层、表单流程、视觉风格和主路径效率。

## 本项目标准

本项目不依赖 Figma。UI 设计阶段默认交付高保真、可交互、本地可打开的 HTML 原型：

```text
docs/design/prototypes/html/
  index.html
  styles.css
  app.js
  assets/
```

HTML 原型确认后，再进入 Flutter 开发。

## 原型要求

- 使用真实中文文案，不使用大段占位文字。
- 以移动端为主，默认按 Android 手机视口设计。
- 覆盖底部导航、页面跳转、关键弹层和表单输入。
- 覆盖正常、空、错误、待确认等关键状态。
- 样式尽量接近最终 App，包括颜色、字体、间距、按钮、列表、卡片、标签和图标。
- 只使用静态前端数据，不接入真实数据库或后端。
- 可以用原生 HTML/CSS/JS；如确需前端框架，必须保证本地运行简单。

第一版重点验证：

- 打开 App 到完成一次上课记录是否足够短。
- 购课/续费是否能自然形成新课包。
- 没有可用课包、课包过期、待确认扣课时的异常路径是否清楚。
- 备份恢复确认流程是否安全。

## 用户确认标准

进入 Flutter 开发前，用户需要确认：

- 整体视觉风格可以接受。
- 首页和快速记录路径符合预期。
- 关键页面的信息密度合适。
- 文案和按钮含义清楚。
- 主要异常状态不让人困惑。
