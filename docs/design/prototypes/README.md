# Prototypes

可交互 HTML 原型，用于验证页面跳转、弹层、表单流程、视觉风格和主路径效率。

## 当前原型

`html/prototype-v2.html` — 单文件 inline React Flow Demo，iPhone 15 Pro 设备框内。

直接用浏览器打开即可体验，覆盖全部主要页面（首页、成长、设置、课程详情、各类录入表单等）。

详见 `html/README.md`。

## 原型要求

- 使用真实中文文案，不使用大段占位文字。
- 以移动端为主，默认按 iPhone 视口设计。
- 覆盖底部导航、页面跳转、关键弹层和表单输入。
- 样式尽量接近最终 App，包括颜色、字体、间距、按钮、列表、卡片、标签和图标。
- 只使用静态前端数据，不接入真实数据库或后端。

## 用户确认标准

进入 Flutter 开发前，用户需要确认：

- 整体视觉风格可以接受。
- 首页和快速记录路径符合预期。
- 关键页面的信息密度合适。
- 文案和按钮含义清楚。
- 主要异常状态不让人困惑。
