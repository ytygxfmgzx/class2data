# 高保真 HTML 原型

本目录是 UI 设计阶段的主交付物目录。

## 必备文件

```text
index.html
styles.css
app.js
assets/
```

## 范围

第一版 HTML 原型至少覆盖：

- 首页：今天和本周课程、处理状态、快速入口。
- 记录上课：已上课、请假、取消、缺课、补课、扣课确认。
- 课程详情：余额、统计、计划、课包、记录、联系人入口。
- 购课/续费：新课包、费用、课时流水、付款截图入口。
- 回顾：课程统计、孩子时间线、照片墙。
- 设置：备份、恢复、导出、隐私说明。

## 运行方式

优先保证直接打开 `index.html` 可预览。若使用构建工具或本地服务，必须在本文件补充运行命令。

## 开发约束

- 不依赖真实后端。
- 不写入真实数据。
- 不引入会显著增加后续 Flutter 还原成本的复杂动效。
- 页面宽度、字体、间距按移动端优先设计。
- 交互状态通过本地 JS 模拟。
