## 1. 视觉原则

- 界面应像记账工具：紧凑、高效、数据清晰。
- 关键数字（余额、金额、课时、日期）视觉突出，辅助信息弱化。
- 颜色只传达语义（红=欠费、绿=正常、蓝=操作），不用于装饰。
- 列表为主，卡片为辅。行高紧凑，分割线清晰。
- 零装饰：无渐变、无毛玻璃、无 pill 按钮、无 hero 区域、无大圆角。
- 一屏展示尽量多的有效信息，但不堆砌到拥挤。

## 2. 色彩

| --- | --- | --- | --- |

### 2.3 语义浅背景

| 角色 | Token | 色值 | 用途 |
| --- | --- | --- | --- |
| 蓝底 | `--bg-blue` | `#e6f7ff` | 选中态背景、信息提示 |

### 2.4 使用规则

- 主交互色只用 `--blue`，不引入第二品牌色。
- 语义色只用于传达状态含义，不把日历做成彩色块墙。
- 页面背景 `--bg`，内容容器用 `--bg-card`。
- 分组靠分割线和浅灰背景区分，不用大间距留白。

## 3. 字体

### 3.1 字体族

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif
```

直接使用系统字体栈，不引入外部字体文件。

### 3.2 字号层级

| Token | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| `--num-lg` | 28px | 700 | 1.2 | 指标大数字、余额 |
| `--num-md` | 20px | 600 | 1.2 | 中等数字、金额 |
| `--title` | 18px | 600 | 1.3 | 页面标题 |
| `--subtitle` | 15px | 600 | 1.4 | 分区标题、列表行主文本 |
| `--body` | 14px | 400 | 1.4 | 正文、表单 |
| `--caption` | 12px | 400 | 1.3 | 时间戳、状态标签 |
| `--btn` | 14px | 500 | 1 | 按钮文字 |

### 3.3 字体规则

- 不使用负字距。
- 字重只用 400（正文）、500（按钮）、600（标题）、700（强调数字）。
- 大数字用 `--num-lg` 突出，不用大标题字号。
- 按钮文字用 500 字重，不是 700。

## 4. 间距

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sp-xs` | 4px | 图标与文字间距 |
| `--sp-sm` | 8px | 紧凑元素间距 |
| `--sp-md` | 12px | 列表行内边距、表单间距 |
| `--sp-lg` | 16px | 页面左右边距、卡片内边距 |
| `--sp-xl` | 20px | 区块间距 |
| `--sp-2xl` | 24px | 大分组间距 |

规则：

- 手机页面左右边距 16px。
- 列表行高 48px。
- 卡片内边距 12-16px。
- 分组间距 16-20px。
- 不使用 32px 以上的间距。

## 5. 形状

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-sm` | 2px | 标签、小控件 |
| `--r-md` | 4px | 按钮、输入框、卡片 |
| `--r-lg` | 6px | 底部弹层顶部 |
| `--r-full` | 999px | 仅用于头像 |

规则：

- 按钮使用 4px 圆角。
- 卡片使用 4px 圆角。
- 标签使用 2px 圆角。
- 彻底取消 pill 按钮和 8px 以上大圆角（头像除外）。

## 6. 阴影和层级

**不使用阴影。** 层级表达靠：
- 背景色差异（`--bg` vs `--bg-card`）
- 1px `--border` 边框
- 分割线

唯一例外：底部弹层使用 `0 -1px 4px rgba(0,0,0,0.08)` 轻微投影区分层级。

## 7. 组件

### 7.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 | bg `--blue`, text 白, 圆角 4px, 高 40px, 字重 500 | 保存、确认、记录上课 |
| 次按钮 | bg 白, border 1px `--border`, text `--text-1`, 圆角 4px, 高 40px | 取消、次要操作 |
| 文字按钮 | 无背景无边框, text `--blue`, 字重 500 | 链接、查看全部 |
| 图标按钮 | 无背景无边框, text `--text-2`, 40x40px 触控区 | 返回、关闭、更多 |

按下态：`opacity: 0.7`。

### 7.2 筛选控件

紧凑 Chip：
- 高度 28px，左右 padding 10px，字号 12px，字重 500
- 未选中：白底 + 1px `--border`
- 选中：`--bg-blue` 背景 + `--blue` 文字
- 圆角 4px（非 pill）

### 7.3 列表行

核心展示组件：

```text
┌──────────────────────────────────┐
│ 主文本              右侧值/状态  │
│ 副文本（灰色小字）               │
├──────────────────────────────────┤
│ 下一条                           │
└──────────────────────────────────┘
```

- 容器：`--bg-card`，无圆角或 2px
- 行高 48px
- 分割线 1px `--border`
- 左右 padding 16px

### 7.4 课程块

日历中的课程项：

```text
18:30  钢琴 · 安安           [待处理]
       星海音乐中心
```

- 高度压缩，一行展示核心信息
- 时间左对齐，课程+孩子在中间，状态标签右对齐
- 背景 `--bg-card`，1px `--border`，圆角 4px
- 状态标签 2px 圆角小色块

### 7.5 指标卡

课程详情数字展示区：

```text
┌──────────┐ ┌──────────┐
│ 剩余课时  │ │ 已花费    │
│ 4 课时    │ │ ¥4,800   │
└──────────┘ └──────────┘
```

- 标签：`--caption` (12px) + `--text-3`
- 数字：`--num-lg` (28px/700) + `--text-1`
- 负数或不足时数字使用 `--red`
- 背景 `--bg-card`，1px `--border`，圆角 4px

### 7.6 照片组件

- 照片墙使用 3 列网格。
- 照片查看器使用 `#111111` 深色背景。
- 事件语境使用底部信息区，不遮挡照片主体。

## 8. 图标

- 优先使用系统图标库（Cupertino Icons / Material Icons）。
- 图标只用于导航和明确动作，不用于装饰。

| 功能 | 图标 |
| --- | --- |
| 首页 | calendar_today |
| 成长 | auto_awesome |
| 设置 | settings |
| 记录上课 | edit_note |
| 课时包 | inventory_2 |
| 课程 | menu_book |
| 成就 | emoji_events |
| 孩子 | person_add |
| 照片墙 | photo_library |

### 8.1 App 图标

- 当前 App 图标母版：`app/assets/branding/app_icon.png`。
- 品牌意象：书本代表“课”，脚印代表“记录与成长痕迹”，低饱和课程标记代表多类型课外班。
- 图标保持白色/浅色基底，保留极淡浅蓝底形或轻投影来支撑边界，不使用透明背景作为发布母版。
- 母版要求：正方形 PNG，推荐 1024×1024，不透明，保留足够留白，避免文字、小尺寸复杂细节和强装饰。
- 平台图标由 `flutter_launcher_icons` 从母版生成，配置在 `app/pubspec.yaml`。
- 更新图标时，替换母版后在 `app/` 目录运行 `dart run flutter_launcher_icons`，再执行 `flutter analyze` 和 `flutter test`。

## 9. 页面模板

### 9.1 Tab 页

```text
标题行 (36px 高, 18px/600 标题)
核心内容
底部 Tab Bar (白底 + 顶部 1px 分割线)
```

### 9.2 二级页

```text
返回 + 标题 (18px/600) + 右侧动作
内容分组 (紧凑列表行)
可选底部主按钮
```

### 9.3 表单页 / 底部弹层

```text
标题 + 关闭按钮
紧凑表单行 (4px 圆角输入框)
底部主按钮 (蓝底白字 4px 圆角)
```

### 9.4 照片查看器

```text
深色背景 (#111111)
照片大图
左右滑动
底部事件语境信息区
```

## 10. 可访问性

- 触控目标不小于 44×44px。
- 文字和背景对比度满足 WCAG AA。
- 状态不只靠颜色表达，搭配文字标签。
- 底部 Tab 和主按钮避开系统手势区。

## 11. P4 通过标准

- 视觉系统自主定义，不依赖外部设计系统。
- 信息密度高，一屏展示尽量多的有效数据。
- 颜色全部传达语义，无装饰性用色。
- 组件紧凑：4px 圆角、48px 行高、无阴影。
- 日常记录路径不超过 3 步操作。
