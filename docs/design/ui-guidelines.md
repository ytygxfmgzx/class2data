# UI 交互规范

- 版本：v0.5

- 设计方向：实用工具型 — 高信息密度、功能优先、零装饰

## 1. 总体原则

- 界面像记账工具：紧凑、高效、数据一眼可见。
- 关键数字视觉突出，辅助信息弱化，不浪费屏幕空间。
- 列表为主，分割线清晰，行高紧凑。
- 颜色只传达语义，不用于装饰。
- 常用路径保持短，首页记录上课不超过 3 步。

## 2. 导航规范

底部 Tab 固定：

| Tab | 标签 | 说明 |
| --- | --- | --- |
| 首页 | 首页 | 快捷入口 + 课程日历 |
| 成长 | 成长 | 成长动态 + 照片墙入口 |
| 设置 | 设置 | 孩子、课程、计划和系统配置 |

规则：

- Tab Bar 白底 + 顶部 1px `--border` 分割线，不使用毛玻璃。
- 当前 Tab 图标和文字使用 `--blue`，非当前使用 `--text-3`。
- 表单和照片查看器可隐藏底部 Tab。

## 3. 顶部栏规范

- Tab 页使用紧凑标题行（36px 高，18px/600 标题），不做 Large Title。
- 二级页使用轻量导航栏：返回图标 + 标题（15px/600） + 右侧动作。
- 顶部栏白底，底部 1px `--border` 分割线，不使用阴影。
- 页面标题要短，详细对象信息放在内容区。

## 4. 首页规范

结构：

```text
紧凑标题行（右上角 + 按钮）
孩子筛选 + 课程筛选
周视图（单行 7 列日期）
当日课程列表
```

### 4.1 快捷入口（右上角加号）

标题行右侧放置"+"按钮，点击弹出菜单，菜单项顺序固定：

1. 记录上课（字重 600，排在首位）
2. 录入课时包
3. 录入课程
4. 录入成就
5. 录入孩子

规则：

- "+"按钮：40x40px 触控区，字号 20px，`--text-1`。
- 弹出菜单：白底，1px `--border`，4px 圆角，出现在按钮下方。每行高 44px，左侧图标 + 文字。
- 点击菜单项执行对应操作，点击遮罩或菜单外区域关闭。
- 前置条件不足时，点击后引导下一步。

### 4.2 课程日历

- 默认全部孩子 + 全部课程。
- 孩子筛选使用头像 Chip（28px 高），课程筛选使用文字 Chip。
- 周视图：单行 7 列，每格只显示日期数字，选中日期下方蓝色短横线。可左右切换周。
- 课程列表：每条使用紧凑课程块（见 visual-system.md 7.4）。
- 点击课程块进入课程详情，块上有"记录"按钮直接进入记录上课。
- 课时不足的课程在课时数旁显示 `--red` 或 `--orange` 警示。

## 5. 成长页规范

结构：

```text
紧凑标题行
孩子筛选（头像 Chip）
照片墙入口（紧凑横条）
成长动态列表
```

规则：

- 默认展示全部孩子动态。
- 照片墙入口使用紧凑横条：左侧图标 + "照片墙" + 右侧箭头 + 最近 3 张缩略图（24x24）。
- 动态使用紧凑列表行，每行 56-64px。
- 每条动态展示：时间 + 孩子名 + 事件类型 + 课程名。
- 有照片的动态在左侧显示 32x32 小缩略图。

## 6. 课程详情规范

课程详情是课程总览页。

首屏优先展示：

- 课程名称、孩子、机构和状态（一行展示）。
- 紧凑指标网格（2x3 或 3x2）：剩余课时、已花费、已上课时、累计时长等。
- 操作按钮行：记录上课（主按钮） + 录入课时包（次按钮）。
- Tab 切换：计划 / 记录 / 课包。

规则：

- 指标数字使用 `--num-lg` (28px/700)，标签使用 `--caption` (12px)。
- 指标网格背景 `--bg-card`，1px `--border`，圆角 4px，内边距 12px。
- 计划和记录使用紧凑列表行展示。
- 课时不足时数字使用 `--red`。

## 7. 照片墙规范

照片墙是集中展示所有照片的入口。

规则：

- 从成长页进入时继承孩子筛选。
- 照片网格 3 列，正方形缩略图，间距 2px。
- 照片下方显示日期（12px `--text-3`）。
- 点开照片进入查看器，支持左右滑动。
- 查看器必须展示事件语境。

照片查看器：

- 深色背景 `#111111`。
- 照片大图居中。
- 底部语境信息区：来源对象、时间、孩子、课程、说明。
- 文字白色，12px。

## 8. 设置和管理规范

- 设置页使用 iOS 风格分组列表。
- 分组标题：12px `--text-3`，左对齐，距上方 20px。
- 列表容器：`--bg-card`，无圆角，无外边框。
- 列表行高 48px，行间 1px `--border` 分割线。
- 每行：左侧图标 + 主文本，右侧副文本 + 箭头。
- 危险操作（归档、删除）使用 `--red` 文字，必须确认。

## 9. 表单规范

- 表单使用紧凑列表样式。
- 输入框：圆角 4px，1px `--border`，内边距 10px 12px，高 40px。
- 输入框焦点态：边框 `--blue`，无额外阴影。
- 标签在输入框上方，12px `--text-2`，距输入框 4px。
- 必填字段靠前，选填字段靠后。
- 日期、时间、状态、课包选择使用选择器，不让用户手输。
- 主按钮：蓝底白字，圆角 4px，高 40px，字重 500。
- 有编辑内容时返回需要提示确认。
- 默认值必须可改。

### 9.1 记录上课弹层

- 底部弹层，从下方滑入。
- 顶部圆角 6px，拖拽条。
- 紧凑表单行：课程、孩子、日期时间、课时包、扣课时、状态、备注。
- 状态选择使用横向紧凑标签组（2px 圆角小色块）。
- 扣课时使用步进器（±0.5）。
- 底部主按钮"保存记录"。

## 10. 状态规范

必须覆盖：

- 正常。
- 空状态。
- 加载。
- 错误。
- 筛选无结果。

空状态规则：

- 文案短（一行）。
- 给一个明确动作按钮。
- 不使用大插画，用文字 + 图标即可。

错误状态规则：

- 附件失败不影响业务记录保存。
- 备份恢复失败要说明原因。
- 课包推荐失败显示待确认。

## 11. 文案规范

| 场景 | 文案 |
| --- | --- |
| 快捷记录 | 记录上课 |
| 课包 | 录入课时包 |
| 课程 | 录入课程 |
| 成就 | 录入成就 |
| 孩子 | 录入孩子 |
| 空孩子 | 先添加一个孩子 |
| 空课程 | 给孩子添加一门课程 |
| 空计划 | 添加上课计划 |
| 空照片 | 还没有照片 |
| 待确认扣课 | 待确认扣课 |

## 12. P4 通过标准

- UI 结构符合三 Tab 架构。
- 视觉表达对齐 visual-system.md v0.5 token 体系。
- 信息密度高：首页首屏展示完整周视图 + 2-3 条课程。
- 列表行高 48px，紧凑一致。
- 按钮圆角 4px，无 pill 按钮。
- 颜色全部传达语义，无装饰性用色。
- 首页课程日历和快捷按钮条清晰。
- 课程详情指标网格紧凑有效。
- 记录上课路径不超过 3 步。
- HTML 原型已按实用工具型重做。
