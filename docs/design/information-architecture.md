## 1. 设计原则

- 底部导航只保留三个 Tab：首页、成长、设置。
- 首页回答“有哪些课、什么时候上、现在要记什么”，由快捷入口和课程日历构成。
- 成长回答“孩子最近发生了什么”，默认展示所有孩子的成长动态流。
- 设置回答“基础数据和系统配置在哪里维护”，包含孩子管理、课程管理、课程计划维护、备份、通知和标签。
- 课程日历只放在首页，不再重复设置独立课程 Tab。
- 首页课程日历默认展示全家所有课程，并支持按孩子、按课程筛选。
- 高频录入优先级固定为：记录上课记录、录入课时包、录入课程、录入成就、录入孩子。
- 管理类列表放到设置，不占据日常记录和成长回顾的一级空间。

## 2. 一级导航

| Tab | 功能定位 | 默认展示 | 典型任务 |
| --- | --- | --- | --- |
| 首页 | 看课程和快速录入 | 快捷入口 + 全家课程日历 | 看今天/本周课程、记录上课、录入课包/课程/成就/孩子 |
| 成长 | 看孩子轨迹 | 所有孩子成长动态流 + 照片墙入口 | 回顾上课、成就、照片、购课动态，按孩子筛选 |
| 设置 | 管理基础数据和系统配置 | 管理入口与设置菜单 | 管理孩子、课程、课程计划、备份恢复、通知、标签 |

## 3. 首页信息架构

首页是 App 的主工作台，日历是首页主体，不再拆到单独 Tab。

```text
首页
├── 顶部概览
│   ├── 今天日期
│   ├── 今日待处理数量
│   └── 课时不足 / 课包到期提醒摘要
├── 快捷录入区（固定优先级）
│   ├── 记录上课
│   ├── 录入课时包
│   ├── 录入课程
│   ├── 录入成就
│   └── 录入孩子
├── 课程日历
│   ├── 筛选器
│   │   ├── 孩子：全部 / 单个孩子
│   │   └── 课程：全部 / 单门课程
│   ├── 视图切换：日 / 周
│   ├── 日历课程块
│   └── 当前日期课程列表
└── 空状态引导
    ├── 无孩子 -> 录入孩子
    ├── 有孩子无课程 -> 录入课程
    ├── 有课程无课包 -> 录入课时包
    └── 有课程无计划 -> 添加上课计划或手动补录
```

### 3.1 快捷录入规则

快捷入口顺序必须稳定：

1. 记录上课记录
2. 录入课时包
3. 录入课程
4. 录入成就
5. 录入孩子

入口行为：

- “记录上课”优先使用首页日历当前筛选范围；若当天只有一节待处理课，直接进入记录表单。
- “录入课时包”需要先确定课程；若当前课程筛选为单门课程，可直接带入该课程。
- “录入课程”需要先确定孩子；若当前孩子筛选为单个孩子，可直接带入该孩子。
- “录入成就”需要先确定孩子，可选关联课程；若当前筛选能推断孩子或课程，应自动带入但允许修改。
- “录入孩子”直接进入孩子表单。

### 3.2 课程日历筛选规则

- 默认筛选为“全部孩子 + 全部课程”。
- 选择某个孩子后，课程筛选器只展示该孩子名下课程。
- 选择某门课程后，孩子筛选自动体现该课程归属孩子，或保持只读提示。
- 清除课程筛选后，回到当前孩子筛选范围内的全部课程。
- 日历课程块必须显示孩子、课程、时间、地点和处理状态。
- 同一时间多个孩子或多门课程有安排时，日历上同时展示，不能互相覆盖。
- 已处理课程显示已上课、请假、取消、缺课等状态。

### 3.3 首页跳转

```text
首页快捷入口 -> 记录上课 -> 保存 -> 首页
首页快捷入口 -> 课包表单 -> 保存 -> 课程详情 / 首页
首页快捷入口 -> 课程表单 -> 保存 -> 课程详情 / 首页
首页快捷入口 -> 成就表单 -> 保存 -> 成长动态 / 首页
首页快捷入口 -> 孩子表单 -> 保存 -> 首页

首页日历课程块 -> 记录上课
首页日历课程块 -> 课程详情
首页日历课程块 -> 上课记录详情（已处理）
```

## 4. 成长信息架构

成长 Tab 默认展示类似“朋友圈”的成长动态流。孩子列表只是筛选和管理入口的一部分，不是主体。

```text
成长
├── 孩子筛选器
│   ├── 全部（默认）
│   ├── 孩子 A
│   └── 孩子 B
├── 快捷操作
│   └── 录入成就
├── 照片墙入口
│   ├── 最近照片预览
│   └── 点击 -> 照片墙
├── 成长动态流
│   ├── 日期分组
│   ├── 上课动态卡
│   ├── 成就动态卡
│   ├── 照片动态卡
│   └── 购课动态卡
└── 孩子摘要入口
    └── 点击 -> 孩子详情
```

### 4.1 动态流事件来源

| 事件类型 | 来源 | 展示内容 | 点击后 |
| --- | --- | --- | --- |
| 上课 | 上课记录 | 孩子、课程、状态、时长、扣课时、照片摘要 | 上课记录详情 |
| 成就 | 成就记录 | 孩子、类型、标题、关联课程、附件摘要 | 成就详情 |
| 照片 | 附件 | 孩子、课程或成就、缩略图 | 照片查看器 |
| 购课 | 课包 / 费用 | 孩子、课程、课包类型、课时 / 金额摘要 | 课包详情 |

### 4.2 成长筛选规则

- 默认展示全部孩子动态。
- 切换孩子后，只展示该孩子相关上课、成就、照片和购课动态。
- 照片墙入口跟随当前孩子筛选；“全部”时展示所有孩子照片，选择单个孩子时只展示该孩子照片。
- 照片墙内部继续支持按课程、月份、来源对象和类型筛选。
- 照片墙是所有照片的集中展示入口，不只是动态流中的照片摘要。
- 从照片墙点开照片后进入照片查看器，支持左右滑动查看前一张 / 后一张。
- 照片查看器必须展示照片的事件语境，包括来源对象、发生时间、孩子、课程和说明。例如：这张照片来自某次上课记录，或来自某个孩子成就。
- 单个孩子家庭也保留“全部”的语义，但筛选器可以弱化展示。
- 添加孩子、编辑孩子放在设置的孩子管理中；成长页只保留必要的孩子详情入口。

## 5. 设置与管理信息架构

设置不只是系统开关，也承载低频但重要的基础数据维护。

```text
设置
├── 数据管理
│   ├── 孩子管理
│   │   ├── 孩子列表
│   │   ├── 添加 / 编辑孩子
│   │   └── 孩子归档
│   ├── 课程管理
│   │   ├── 课程列表
│   │   ├── 添加 / 编辑课程
│   │   ├── 课程详情
│   │   └── 课程计划维护
│   │       ├── 计划列表
│   │       ├── 添加 / 编辑计划
│   │       └── 冲突提示
│   └── 标签管理
├── 数据安全
│   └── 备份与恢复
├── 提醒
│   └── 通知设置
└── 关于
```

### 5.1 孩子管理

- 用于新增、编辑、归档孩子。
- 孩子的成长动态不在这里作为主入口展示；成长回顾仍在成长 Tab。
- 有历史记录的孩子不能无提示硬删除，应优先归档。

### 5.2 课程管理

- 用于新增、编辑、归档课程。
- 课程详情可查看课包、计划、上课记录、课时账本、联系人和统计。
- 课程计划维护属于课程管理的一部分，不作为单独一级入口。

### 5.3 课程计划维护

- 从设置 -> 课程管理 -> 课程详情或课程计划入口进入。
- 支持按孩子、课程、状态筛选计划。
- 支持添加、编辑、暂停、结束计划。
- 计划保存后，首页课程日历立即按筛选规则展示对应排期。

## 6. 课程详情信息分组

课程详情是从首页课程日历点击课程后的主要落点，不只是管理页。它要回答家长对这门课最关心的整体问题：这个孩子在这门课上一共买了多少课、花了多少钱、还剩多少课、已经持续了多久、实际上了多长时间、后面怎么排课。

```text
课程详情
├── 课程头部
│   ├── 孩子、课程名、机构、地点、状态
│   └── 编辑课程名称 / 基础信息
├── 快捷操作
│   ├── 记录上课
│   ├── 录入课时包
│   ├── 修改课程计划
│   └── 编辑课程
├── 课程总览
│   ├── 已购课时
│   ├── 已花费金额
│   ├── 剩余课时
│   ├── 待确认扣课
│   ├── 上课次数
│   ├── 累计实际时长
│   ├── 课程持续周期
│   └── 课包到期提醒
├── 课程计划日历
│   ├── 日 / 周视图
│   ├── 计划课
│   ├── 已处理上课记录
│   └── 冲突提示
├── 课包列表
├── 上课记录
├── 课时账本
├── 联系人
└── 课程统计
```

### 6.1 课程总览指标口径

| 指标 | 口径 |
| --- | --- |
| 已购课时 | 该课程所有固定课时课包的购入课时合计；周期卡或不限次卡单独展示有效期语义 |
| 已花费金额 | 该课程费用记录金额合计，按实际录入金额统计 |
| 剩余课时 | 由该课程课时流水求和得到，不靠手工余额字段 |
| 待确认扣课 | 已记录上课但尚未明确课包的扣课流水 |
| 上课次数 | 已上课、补课等实际发生课程记录数；请假、取消不计入实际上课次数 |
| 累计实际时长 | 上课记录中的实际时长合计，不等同于消耗课时 |
| 课程持续周期 | 从第一条有效购课、计划或上课记录到当前日期 / 最后一条记录的时间跨度 |

### 6.2 课程详情可编辑项

- 可编辑课程名称、分类、机构、地点、默认扣课时、默认时长、备注。
- 可进入课程计划维护，添加、编辑、暂停或结束计划。
- 可录入课时包，形成新课包、费用记录和正向流水。
- 可记录上课，形成上课记录和必要的负向流水。
- 可进入课时账本做手动调整，但必须填写备注。

## 7. 页面层级原则

- 首页和成长是面向日常使用的内容页。
- 设置是面向低频维护的管理页。
- 课程详情可以从首页日历、成长动态和设置课程管理进入。
- 孩子详情可以从成长动态和设置孩子管理进入。
- 表单保存后优先返回触发页面；从首页快捷入口进入的表单保存后可回首页并给出查看详情入口。

## 8. 空状态优先级

| 场景 | 首页主引导 | 设置管理入口 |
| --- | --- | --- |
| 无孩子 | 录入孩子 | 设置 -> 孩子管理 |
| 有孩子无课程 | 录入课程 | 设置 -> 课程管理 |
| 有课程无计划 | 添加上课计划或手动补录 | 设置 -> 课程管理 -> 课程计划维护 |
| 有课程无课包 | 录入课时包 | 课程详情 -> 课包列表 |
| 有记录无成就 | 录入成就 | 成长 Tab |

## 9. P3 通过标准

- 底部导航只有首页、成长、设置三个 Tab。
- 首页包含快捷入口和课程日历，课程日历不再作为独立 Tab 重复出现。
- 首页课程日历默认加载全部孩子、全部课程，并支持按孩子和课程筛选。
- 成长 Tab 默认展示所有孩子的成长动态流，而不是孩子列表。
- 设置中包含孩子管理、课程管理和课程计划维护。
- 课程计划维护保存后能回流到首页课程日历展示。
- 日常记录路径仍支持不超过 10 秒的目标。
