# Wireframes

本目录存放可选的低保真页面线框图，用于在复杂流程早期确认信息结构、布局和操作路径。

本项目 UI 确认主产物是 [../prototypes/html/README.md](../prototypes/html/README.md) 中的高保真可交互 HTML 原型。若流程已经能直接通过 HTML 原型表达，可以跳过单独 wireframe。

推荐格式：

- `.svg`：适合版本管理和人工查看。
- `.png`：适合快速预览。
- `.html`：适合带少量交互的线框原型。

第一版如需先做低保真草图，建议覆盖：

- `home.svg`：首页今日/本周课程和快速记录入口。
- `record-class.svg`：处理计划课、选择状态、确认扣课。
- `course-detail.svg`：课程详情、余额、记录、课包、计划入口。
- `package-form.svg`：购课/续费表单。
- `backup-restore.svg`：备份、恢复、导出入口和确认流程。

线框图不是最终视觉稿，也不是进入开发的必需门禁；HTML 原型和用户确认才是必需门禁。
