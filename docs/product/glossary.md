## 1. 使用规则

- 产品、设计、开发、测试文档应优先使用本文术语。
- 如果出现新概念，应先判断是否能归入已有术语；不能归入时再新增。
- 涉及余额、课包、流水、附件和备份的术语，不应在不同文档中改变含义。
- 系统语义类型和普通分类标签必须区分，不能混用。

## 2. 核心对象

| 术语 | 英文 / 代码名 | 定义 | 备注 |
| --- | --- | --- | --- |
| 家长 | Parent | 第一版唯一主要用户，负责记录和查看数据。 | 不单独建复杂多用户模型。 |
| 孩子 | Child | 家庭中的一个孩子，是课程、成长时间线和照片回顾的重要维度。 | 一个孩子可以有多门孩子课程。 |
| 孩子课程 | KidCourse | 某个孩子正在上的某门课。 | 第一版最核心的聚合对象，例如“哥哥的篮球课”。 |
| 课程 | Course | 用户界面上对孩子课程的简称。 | 除非讨论领域模型，否则通常等同于孩子课程。 |
| 机构 | Organization | 培训机构、场馆或课程提供方。 | 第一版只作为文本字段，不单独维护机构档案。 |
| 联系人 | Contact | 老师、教练、顾问等课程相关联系人。 | 归属于孩子课程。 |
| 成就记录 | Achievement | 奖项、证书、演出、比赛、阶段成果等成长事件。 | 归属于孩子，可选关联孩子课程。 |
| 附件 | Attachment | 照片、付款截图、奖状、合同截图等文件及其元数据。 | 文件本体进入 App 私有目录。 |

## 3. 课程计划与上课记录

| 术语 | 英文 / 代码名 | 定义 | 备注 |
| --- | --- | --- | --- |
| 上课计划 | CourseSchedule | 某门孩子课程未来或规律性的上课安排。 | 计划不等于实际上课记录。 |
| 待处理课程 | Pending Class | 由启用中的上课计划在运行时生成的近期待处理项。 | 不提前批量写入全部未来课程。 |
| 计划课 | Scheduled Occurrence | 某个上课计划在某一天某一时间生成的一节待处理课程。 | 处理后应能防重复。 |
| 上课记录 | ClassRecord | 某次上课、请假、取消、缺课或补课的事实事件。 | 保存后以本次记录为准。 |
| 已上课 | Attended | 用户确认孩子实际完成了本次课程。 | 可扣课，也可根据实际情况不扣课。 |
| 请假 | Leave | 用户提前或事后记录本次课程请假。 | 通常不扣课，除非用户明确记录扣课。 |
| 取消 | Cancelled | 课程本身取消或本次不用上。 | 通常不扣课。 |
| 缺课 | Absent | 应上课但孩子未参加。 | 是否扣课以本次记录为准。 |
| 补课 | Makeup | 为补回此前缺失或调整的课程而上的课。 | 是否扣课以本次记录为准。 |
| 上课类型 | Class Type | 常规课、寒暑假班、集训、补课等普通分类标签。 | 历史记录保存当时显示名称。 |
| 阶段性计划 | Period Plan | 寒暑假班、集训等在一段时间内密集发生的计划。 | 第一版支持录入和冲突提示。 |
| 冲突提示 | Conflict Warning | 同一孩子的计划时间重叠时给出的提示。 | 第一版提示冲突，但不自动生成完整排课方案。 |

## 4. 课包、费用和课时账本

| 术语 | 英文 / 代码名 | 定义 | 备注 |
| --- | --- | --- | --- |
| 课包 | Package | 一次购课、续费或赠课形成的权益。 | 一次付款或赠课必须创建一个新课包。 |
| 课时包 | Lesson Pack | 有固定总课时的课包。 | 余额由课时流水计算。 |
| 周期卡 | Period Pass | 在一定有效期内可上课的课包，可能没有固定总课时。 | 不伪造课时余额。 |
| 不限次卡 | Unlimited Pass | 有效期内不限次数或不按固定课时扣减的课包。 | 按有效期或不限次语义展示。 |
| 寒暑假包 | Holiday Package | 针对寒假、暑假课程单独购买的课包。 | 不默认并入常规课包。 |
| 集训包 | Intensive Package | 针对集训课单独购买的课包。 | 可有特殊课时消耗。 |
| 赠课包 | Gift Package | 机构赠送形成的课包。 | 金额可以为空。 |
| 费用记录 | Payment | 购课、续费、退款或其他费用投入记录。 | 归属于孩子课程，可关联课包。 |
| 付款截图 | Payment Screenshot | 付款凭证图片。 | 作为附件关联到费用或课包。 |
| 课时 | Credit | 用于记录课程权益和消耗的单位。 | 存储使用定点整数，不用浮点数。 |
| 课时单位 | Credit Units | 课时的内部定点整数表示。 | 建议 `100 = 1 课时`。 |
| 课时流水 | CreditTransaction | 课时变化账本。 | 购入为正，消耗为负，余额由流水求和。 |
| 正向流水 | Positive Transaction | 增加课时的流水，例如购课或赠课。 | 通常关联课包。 |
| 负向流水 | Negative Transaction | 减少课时的流水，例如销课。 | 必须与本次记录语义一致。 |
| 调整流水 | Adjustment Transaction | 用户为修正余额创建的课时变化记录。 | 必须填写备注。 |
| 待确认扣课 | Pending Deduction | 需要扣课但暂时无法确定课包的记录或流水。 | 后续补选课包后入账。 |
| 课程余额 | Course Balance | 某门孩子课程下所有课时流水求和得到的余额。 | 不手工维护单个余额字段。 |
| 课包余额 | Package Balance | 某个课包关联流水求和得到的余额。 | 周期卡可无课时余额。 |
| 销课 | Deduct Credits | 根据上课记录扣减课时。 | 产品文案可用“扣课时”降低理解成本。 |
| 扣课时 | Credit Cost | 本次上课记录消耗的课时数。 | 可以是 0、0.5、1、1.5、2 或自定义。 |

## 5. 统计和回顾

| 术语 | 英文 / 代码名 | 定义 | 备注 |
| --- | --- | --- | --- |
| 上课次数 | Class Count | 符合统计口径的上课记录数量。 | 不等于消耗课时。 |
| 实际上课时长 | Duration Minutes | 本次或累计实际上课分钟数。 | 不等于消耗课时。 |
| 消耗课时 | Consumed Credits | 消耗类课时流水求和的绝对值。 | 集训可能 1 次课消耗 2 课时。 |
| 费用投入 | Total Payment | 费用记录金额求和。 | 金额内部以分为单位。 |
| 当前剩余 | Current Balance | 课程或课包当前可解释的剩余权益。 | 由流水求和或有效期语义展示。 |
| 孩子时间线 | Child Timeline | 聚合孩子购课、上课、成就和照片的时间线。 | 用于成长回顾。 |
| 课程统计 | Course Statistics | 某门课程的次数、时长、课时、费用、成就和照片汇总。 | 统计口径必须可解释。 |
| 照片墙 | Photo Wall | 按孩子、课程、月份等筛选的照片集合。 | 丢失文件不能展示为正常图片。 |

## 6. 附件、备份和导出

| 术语 | 英文 / 代码名 | 定义 | 备注 |
| --- | --- | --- | --- |
| App 私有目录 | App Private Directory | 手机系统为 App 分配的私有存储区域。 | 数据库和附件默认保存于此。 |
| 相对路径 | Relative Path | 附件在 App 私有目录内的相对位置。 | 数据库不保存依赖系统环境的绝对路径。 |
| 绝对路径 | Absolute Path | 包含完整设备目录的文件路径。 | 附件数据库字段不应依赖它。 |
| 备份包 | Backup Package | 用户手动导出的完整 zip 文件。 | 第一版普通导出，不要求密码加密。 |
| manifest | manifest.json | 备份包中的清单文件。 | 记录应用版本、数据库版本、导出时间和附件清单。 |
| 恢复 | Restore | 从备份包恢复数据库和附件。 | 恢复前必须用户确认。 |
| 半恢复 | Partial Restore | 数据库和附件只恢复一部分的不一致状态。 | 第一版必须避免。 |
| JSON 导出 | JSON Export | 导出结构化数据便于迁移或长期保存。 | 不替代完整备份。 |
| CSV 导出 | CSV Export | 导出表格化数据便于人工查看。 | 不替代完整备份。 |
| 备份加密 | Encrypted Backup | 对备份包进行密码加密。 | 第一版范围外。 |

## 7. 类型、标签和状态

| 术语 | 定义 | 例子 | 规则 |
| --- | --- | --- | --- |
| 系统语义类型 | 影响系统计算、对象归属或底层逻辑的固定类型。 | `Package.type`、`CourseSchedule.schedule_type`、`CreditTransaction.type`、`Attachment.owner_type`、`Attachment.file_type` | 不允许用户改名或新增业务含义。 |
| 普通分类标签 | 主要用于展示、筛选和统计的分类。 | 课程分类、上课类型、费用类型、成就类型、联系人角色 | 用户可新增或隐藏，历史记录保留当时显示名称。 |
| 稳定 code | 存入数据库用于表示系统语义的稳定英文代码。 | `lesson_pack`、`weekly_repeat`、`consume` | 不随中文显示名变化。 |
| 显示名称 | 用户界面显示的中文名称。 | 课时包、每周重复、消耗 | 可由映射或标签提供。 |
| 显示名称快照 | 历史记录保存的当时显示名称。 | `class_type_name_snapshot` | 防止标签改名影响历史理解。 |
| 归档 | Archive | 不再日常使用，但保留历史数据。 | 用于有历史记录的孩子和课程。 |
| 作废 | Void | 标记课包或账本相关对象不再有效。 | 不应静默删除历史流水。 |
| 启用 | Active | 计划、课程或提醒处于可使用状态。 | 启用计划可生成待处理课程。 |
| 暂停 | Paused | 暂时不参与日常生成或提醒。 | 暂停计划不生成待处理课程。 |
| 结束 | Ended | 计划或课程已结束。 | 结束计划不生成待处理课程。 |

## 10. 易混淆术语

### 孩子课程 vs 机构课程

- 孩子课程：某个孩子正在上的某门课，是第一版核心对象。
- 机构课程：机构内部定义的班级或课程产品，第一版不单独建模。

### 上课计划 vs 上课记录

- 上课计划：未来或规律性安排，回答“通常什么时候上课”。
- 上课记录：已经发生或已经处理的事实事件，回答“这一次怎么处理”。

### 上课次数 vs 消耗课时

- 上课次数：记录数量。
- 消耗课时：课时流水中的扣减值。
- 一次集训可能上课次数是 1，实际时长是 180 分钟，消耗课时是 2。

### 课程余额 vs 课包余额

- 课程余额：当前课程下所有课时流水求和。
- 课包余额：某个课包关联课时流水求和。

### 附件删除 vs 业务对象删除

- 附件删除：删除附件记录时，直接删除对应私有目录文件。
- 业务对象删除：有历史数据的孩子、课程、课包等不应无提示硬删除。

### 备份 vs 导出

- 备份：用于完整恢复 App 数据，包含数据库和附件。
- 导出：用于查看或迁移，如 JSON / CSV，不替代完整备份。
